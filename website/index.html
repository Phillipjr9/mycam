Frequently Asked Questions

Get answers to common questions

Is root access required?

No! Virtual Camera works without root access. It uses Android's built-in MediaProjection API to create virtual displays.

Which apps can use the virtual camera?

Any app that uses Android's Camera API can use Virtual Camera. This includes Instagram, WhatsApp, TikTok, Snapchat, Facebook, Telegram, and hundreds more.

Can I use my own video files?

Yes! With the Pro plans, you can load and play any video file from your device as your camera feed.

What video formats are supported?

Virtual Camera supports MP4, MOV, AVI, and most common video formats that are playable on Android.

Can I add text overlays?

Yes! All plans include basic text overlay functionality. Pro plans allow for more customization options.

How do I activate my Pro subscription?

After purchasing, you'll receive an activation key via Telegram or Email. Enter this key in the app to unlock Pro features. Each key is cryptographically tied to ONE device only and cannot be transferred.

Can I use the same activation key on multiple devices?

No. Each activation key is tied to a single device's unique identifier. Copying the APK to another device will NOT work. If you need to use Virtual Camera on a different device, you must purchase a separate license.
